# Notebook rendering and licenses

The documentation links to notebook source files; it does not distribute
standalone HTML exports of them. Locally rendering notebooks may incorporate
components provided by the rendering tool. Consult their licenses before
redistributing generated output, including the [nbconvert BSD 3-Clause
license](nbconvert-7.17.2.txt) when applicable.

The PASSAGE notebook sources use the project's MIT license. The dataset and
its derived artifacts have their own attribution and terms. [PASSAGE license](https://github.com/ThalesGroup/passage/blob/main/LICENSE) ·
[Dataset terms](../dataset/index.md#licence-and-attribution)
